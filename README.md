# Miami Prime Mortgage Landing Page

Una landing page moderna y profesional diseñada para Miami Prime Mortgage, enfocada en ofrecer soluciones hipotecarias personalizadas en Miami. Esta página está optimizada para la conversión, con un diseño limpio, animaciones suaves y una experiencia de usuario fluida.

## 🚀 Tecnologías Utilizadas

El proyecto ha sido desarrollado utilizando un stack moderno para asegurar rendimiento y mantenibilidad:

- **[React](https://react.dev/)**: Biblioteca principal para la construcción de la interfaz de usuario.
- **[Vite](https://vitejs.dev/)**: Entorno de desarrollo ultrarrapido.
- **[TypeScript](https://www.typescriptlang.org/)**: Tipado estático para un código más robusto y seguro.
- **[Tailwind CSS](https://tailwindcss.com/)**: Framework de utilidades para un diseño rápido y responsivo.
- **[Framer Motion](https://www.framer.com/motion/)** & **[GSAP](https://greensock.com/gsap/)**: Para animaciones avanzadas y transiciones fluidas.
- **[Lucide React](https://lucide.dev/)**: Colección de iconos ligeros y consistentes.

## 🛠️ Instalación y Configuración

Para ejecutar este proyecto localmente, sigue estos pasos:

1.  **Clonar el repositorio:**

    ```bash
    git clone <URL_DEL_REPOSITORIO>
    cd miami-prime-mortgage
    ```

2.  **Instalar dependencias:**

    ```bash
    npm install
    ```

3.  **Iniciar el servidor de desarrollo:**

    ```bash
    npm run dev
    ```

4.  **Construir para producción:**
    ```bash
    npm run build
    ```

## ☁️ Despliegue en Cloudflare Pages

Este proyecto está configurado para ser desplegado fácilmente en Cloudflare Pages.

1.  Conecta tu repositorio de GitHub/GitLab a Cloudflare Pages.
2.  Configura los ajustes de construcción:
    - **Comando de compilación:** `npm run build`
    - **Directorio de salida:** `dist`
3.  Despliega.
